本轮想请大家重点看

  • 评估页只剩对话框：右侧结果区整块去掉，C 端与 B 端都一样，对话全程全宽
  • 对话里的「评估结果文档」卡片组：本次产出几份就给几份入口（批量结论 / 评估报告 / 分集问题标注），点任意一份都在新页面打开
  • 新的统一结果页：一个页面按 tab 放全部结果——批量评估结果 / 剧本评估报告 / 分集问题标注 / 修改对比，tab 随产出增减
  • 结果页里的一键修复闭环：改完自动多出「修改对比」tab，可按问题 / 按集 / 整本采纳与撤销，改动会同步回评估页的对话框
  • 结果页状态全在网址里：刷新不丢、可直接把链接发给别人，打开就是同一份结果与同一个 tab
  • 报告仍是文档版式：封面信息表 + 章节编号（一 结论 / 二 得分 / 三 详细评估），三个 tab 作为 3.1 / 3.2 / 3.3 小节
  • 选「快速评估」后，报告页上方的升级引导：在结果页里点升级即可就地解锁「分集问题标注」tab
  • 对话答案里的「在结果页查看」跳转按钮，以及原来说「右侧…」的文案是否都改顺了
