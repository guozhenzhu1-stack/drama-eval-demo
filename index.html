本轮想请大家重点看

  • 评估深度用文案当选项（本轮改动）：brief 卡片里「快速评估 / 深度评估」两个胶囊按钮去掉，下方两段说明文案本身变成可点的单选项，选中态是蓝框浅蓝底 + 左侧实心单选点；默认深度评估，方向键可切换
  • 示例剧本要自己点发送才开始（上一轮改动）：点首页的示例只把它填进输入框（文件卡片 + 评估要求，示例按钮停在选中态），改完要求再点右下角发送才发起评估，不再自动跳走
  • 评估报告只留必要信息（上一轮改动）：封面「剧本体量」信息表整块去掉；结论一节只留两段（评级依据、上探路径不再出）；各处「共 N 部分，点下方标签切换查看」式的说明句、tab 副标题与重复的小节标题都删掉；合规规则表只列命中项，通过的合成一句话；分维度标题行压到「维度名 · 分数 · 问题数」。问题位置、原文与判断依据一条没少
  • 对话框视觉与交互对齐参考稿（上一轮改动）：顶部一行是「← 返回」胶囊 + 居中加粗标题 + 右侧 »（收起右侧工作台让对话占满，再点变 « 恢复分栏）；气泡去掉头像与描边，AI 是浅灰底、用户是蓝底右对齐；每条 AI 回复下方有👍 / 👎（互斥，点了会给一句确认）；执行进度改成 ✦ 头像 + 「✓ 步骤名 ›」清单，点任意一行展开这步在做什么，进度条去掉。批量页那条单行滚动进度保持原样
  • 10 集以内的结果用自然语言说（上一轮改动）：这一路的评估结果不再用卡片承载——对话气泡里就是几段话：先交代体量与问题总数、严重度分布，再按维度逐段讲「第几集 · 问题 · 原文 · 判断依据」，其余维度折在一句话后面的「也一并说完」文字链接里；追问「第 3 集有什么问题」同样回自然语言。严重度用「致命 / 严重 / 一般 / 轻微」的说法代替 P0/P1 色块
  • 风格 B 只做问题检测（上一轮改动）：修改建议与改稿入口全部撤掉——对话内不再有「按建议改写 / 全部改掉」，分集问题标注里不再有「整本一键修复 / 本集一键修复 / 一键修复」与划选下指令，「修改对比」tab 不再产出，报告的分维度与合规章节也不再给「建议：…」；剧本正文由可编辑改为只读，每条问题只留严重度、位置（第几集 · 原文）与判断依据，标注卡上只保留「忽略」
  • 升级后入口跟到最新回复下方（上一轮改动）：快速评估里点「升级为深度评估」，「查看完整评估结果」摘要条会从上一条旧消息移到刚生成的那条回复下面——之前它留在原处，看起来像按钮跑到了回复上方
  • 风格 B 的首页对齐参考稿（上一轮改动）：品牌名改成「剧本创作Agent」，左侧栏是首页 / 项目 / Skill 广场 + 最近项目列表，标题「开始一次短剧创作」、副标题与输入框占位符都与参考稿一致；唯一的差异是输入框下方那一行——换成示例剧本，给出一小段 / 单集 / 8 集连续 / 24 集全本四种粒度，点一个把这份示例填进输入框，点发送带着体量进流程
  • 10 集以内不出评分（上一轮改动）：这个体量的结果不给综合评分、评级和维度得分条，只按评估维度讲问题与判断依据；维度按最严重问题排序，前两个维度直接说完、其余收在「也一并说完」后面；这一路仍然完全在对话里，右侧结果区不出现
  • brief 卡片瘦身（上一轮改动）：标题从一长句改成「确认评估口径」；去掉制作方式、目标地区、目标投稿平台三个字段，只保留评估维度（可多选）、其他评估要求和评估深度；确认按钮改成「开始评估」，不再显示积分消耗
  • 报告导出只留 PDF（上一轮改动）：Word 与格式下拉都去掉了，只有一个「⤓ 导出 PDF」按钮，点击后先变「正在生成…」再提示已生成（Demo 不产出真实文件）
  • 结果页 tab 字号放大（上一轮改动）：顶部「剧本评估报告 / 分集问题标注」的标题从 13px 提到 15px、行高 38px，选中态加粗
  • 体量决定流程：首页四个示例分别对应一小段 / 单集 / 8 集 / 24 集全本，也可以自己拖文件进来——集数从文件名解析（解析不到按多集处理）
    • 10 集以内：不问口径，直接在对话里用自然语言按维度把问题说完
    • 10 集及以上：输入框上方出 brief 卡片确认维度与评估深度；选快速评估→ 报告直接摊在对话右侧；选深度评估→ 对话里给一条摘要 + 「查看完整评估结果」按钮，点开是新页面的报告与分集问题标注
    • 快速评估结束后仍可升级为深度评估：升级后右侧报告收起，对话切回摘要条 + 新页面入口
  • 两种视觉风格二选一：风格 A 是原来的顶栏 + 渐变科技感；风格 B 是常驻左侧导航栏、纯白底、发丝描边、单一蓝色强调，去掉了极光背景与发光动效
  • 风格 A 完全没动：上一版的流程与视觉原样保留，两版可以直接对照；风格 B 的流程差异是本轮有意为之，不算 bug
  • 结果页版式（上一轮改动）：tab 组居中，各 tab 的内容统一收进 1320px 版心居中，不再左贴边
  • 分集问题标注加宽：右侧问题栏 352px → 408px，判断依据少折行；正文栏仍保证 720px 的阅读宽度
  • 对话里的结果摘要条：一条摘要 + 一个主按钮，取代原来「评估报告 / 分集问题标注 / 批量结论」三张同级卡片
  • 摘要条里带关键结论：C 端给评级 / 综合分 / 问题数与 P0·P1 分布 / 最弱维度，B 端给 S/A 级、拦截数与有效稿占比——不点开也知道结果好不好
  • 默认路径唯一：主按钮「查看完整评估结果」，「分集问题标注」降级成底部一行细链接；标注的常规入口回到报告里点「第 N 集」
  • 评估页只剩对话框：右侧结果区整块去掉，C 端与 B 端都一样，对话全程全宽
  • 统一结果页：一个页面按 tab 放全部结果，tab 随产出增减——风格 B 本轮只会出「剧本评估报告 / 分集问题标注」（B 端多一个批量评估结果），风格 A 里还保留「修改对比」
  • 结果页里的一键修复闭环（仅风格 A）：改完自动多出「修改对比」tab，可按问题 / 按集 / 整本采纳与撤销；风格 B 本轮已整块去掉
  • 结果页状态全在网址里：刷新不丢、可直接把链接发给别人，打开就是同一份结果与同一个 tab
  • 报告仍是文档版式：封面（书名 + 评级卡）+ 章节编号（一 评估结论 / 二 分维度得分 / 三 详细评估），风格 B 本轮已把封面信息表与小节重复标题去掉；风格 A 保持原样
  • 选「快速评估」后的升级引导：升级后摘要条就地多出「分集问题标注」锚点，在结果页里点升级则就地解锁该 tab
